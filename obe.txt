🔷 OBJECTIVE RULES
Condition	                                                Rule
🟦 Objective State: Draft / Idea / Planned           🔸 Allowed KR states: Draft, Planned, Cancelled
                                                     🔸 Cannot move to In Progress unless the start date is reached
🟩 Objective State: In Progress	                     🔸 KRs can be actively updated (progress + state)
                                                     🔸 KRs must have valid states like In Progress, Cancelled, Completed
🟩 Objective State: Completed	                    🔸 All non-cancelled KRs must be at 100% progress
                                                     🔸 KR editing is disabled
🟥 Objective State: Aborted / Cancelled	            🔸 All KRs automatically move to Cancelled
                                                    🔸 Objective progress is frozen or irrelevant


🔶 KEY RESULT RULES
Condition	                                                Rule
⏳ Before KR start date	                          🔸 Progress = 0%
                                                    🔸 KR state must be: Draft, Planned, or Cancelled
📆 After KR start date	                           🔸 Progress updates allowed (only if objective is In Progress)
                                                    🔸 Allowed KR states: In Progress, Cancelled, Completed
❌ KR State = Cancelled or Aborted	              🔸 KR progress is ignored in objective % calculation
🚫 Objective is NOT in progress                    🔸 KR progress is locked, unless KR is in Planned or Cancelled, 
                                                       Progress must be 0%
✅ KR State = Completed	                          🔸 Progress must be exactly 100%
⚠️ KR State ≠ Completed	                           🔸 Progress must be < 100%
